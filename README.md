# Mou

**Mou** (валенс. «двигайся») — нативное iOS-приложение общественного транспорта региона
Валенсия на открытых данных GTFS. По образцу SBB Mobile / Яндекс.Карт: карта остановок →
тап по станции → расписание → (в планах) планировщик маршрута A→B. Без сервера, офлайн, на
данных по расписанию.

## Структура

| Путь | Что это |
|------|---------|
| `build.py` | Конвертер GTFS → компактный JSON (`data/`) |
| `data/` | Сгенерированный датасет: `stops.json`, `lines.json`, `meta.json` |
| `web/index.html` | Веб-прототип на Leaflet для проверки данных и UX перед портом на SwiftUI |
| `ios/` | Нативное приложение (SwiftUI + MapKit), цель — iOS 17+ |

## Этап 1 — Metrovalencia (метро + трамвай)

144 станции, 10 линий. Источник: официальный GTFS Metrovalencia/FGV
(`metrovalencia.es/google_transit_feed/google_transit.zip`).

- Карта с прогрессивной загрузкой станций по важности (кол-во линий → порог зума) и затуханием.
- Официальные цвета линий, карточка станции в стиле Яндекс.Карт (обзор + расписание на день,
  ближайшие поезда по направлениям, дистанция, адрес, контакт, кнопка «Маршрут»).
- Аэропорт VLC и вокзалы Renfe как спец-маркеры.

### Запуск веб-прототипа

```
python3 -m http.server 8787
# открыть http://localhost:8787/web/index.html
```

### Сборка iOS

```
cd ios
ruby project.rb        # генерирует Mou.xcodeproj
xcodebuild -scheme Mou build
```

## Дорожная карта

- **Этап 1** — Metrovalencia метро + трамвай *(прототип готов)*
- **Этап 2** — электрички Renfe Cercanías
- **Этап 3** — автобусы GVA/EMT + полноценный планировщик маршрутов

## Данные

Все источники открытые: Metrovalencia/FGV, GVA (CC BY), Renfe Cercanías, EMT. Real-time нет —
приложение работает по расписанию.
